# Security

Octomux runs your shells and coding agents, so security reports matter a lot.

**Please don't open a public issue for a vulnerability.** Report it privately through GitHub:
[Report a vulnerability](https://github.com/anilsenay/octomux/security/advisories/new). Include what an attacker
can do, the steps to reproduce, and the affected version. You'll get a reply within a few days.

Only the latest release gets security fixes. Releases are signed with a Developer ID, notarized by Apple, and
updates are verified with an EdDSA signature before they are installed.
